# Montazer Book Store

این پروژه یک صفحه وب ساده برای معرفی و سفارش کتاب‌های نویسنده محمد منتظر است. برنامه شامل صفحه اصلی فروشگاه و پنل مدیریت است و قابلیت ذخیره سفارش‌ها در مرورگر را دارد.

## امکانات

- صفحه اصلی معرفی کتاب‌ها با استایل حرفه‌ای و واکنشگرا
- نمایش گالری تصاویر برای بعضی کتاب‌ها
- فرم ثبت سفارش با انتخاب کتاب، تعداد و توضیحات
- ذخیره سفارش‌ها در `localStorage`
- پنل مدیریت با ورود ساده برای نمایش سفارش‌ها
- تغییر وضعیت سفارش‌ها و حذف سفارش‌ها در پنل مدیریت
- طراحی موبایل‌پسند و ظاهری مدرن با استفاده از Tailwind CSS

## ساختار پروژه

- `index.html` - صفحه اصلی فروشگاه
- `admin.html` - صفحه پنل مدیریت
- `script.js` - کدهای جاوااسکریپت صفحه اصلی
- `admin.js` - کدهای جاوااسکریپت پنل مدیریت
- `src/output.css` - فایل استایل تولیدشده توسط Tailwind
- `style.css` - فایل استایل خالی یا اضافی
- `package.json` - وابستگی‌های Tailwind CSS

## چگونه ساختیم

این پروژه با استفاده از HTML، CSS و JavaScript ساده ساخته شده است. استایل‌ها با Tailwind CSS نوشته شده و فایل خروجی CSS در `src/output.css` قرار دارد.

سفارش‌ها در `localStorage` مرورگر ذخیره می‌شوند تا اطلاعات در همان دستگاه حفظ شود. پنل مدیریت با یک ورود ساده کنترل می‌شود و پس از ورود موفق، سفارش‌ها نمایش داده می‌شوند.

## چطور ادامه دهیم

اگر می‌خواهید برنامه را توسعه دهید، گزینه‌های بعدی عبارتند از:

1. افزودن دیتابیس واقعی یا بک‌اند برای ذخیره و مدیریت سفارش‌ها
2. افزودن احراز هویت امن‌تر برای پنل مدیریت
3. اضافه کردن فرم پرداخت آنلاین یا اتصال به درگاه‌های پرداخت
4. امکان افزودن و ویرایش کتاب‌ها در پنل مدیریت
5. بهبود طراحی و افزودن انیمیشن‌ها یا ترجمه انگلیسی
6. پیاده‌سازی سیستم اعلان برای سفارش‌های جدید

## اجرا

1. صفحه `index.html` را در مرورگر باز کنید.
2. برای ورود به پنل مدیریت، `admin.html` را باز کنید و از نام کاربری `admin` و رمز عبور `1234` استفاده کنید.

## نیازمندی‌ها

- مرورگر وب مدرن
- اینترنت برای بارگذاری Tailwind CSS از CDN در `admin.html`

## توسعه‌دهنده

طراحی و پیاده‌سازی اولیه توسط امیر علی چهاردولی انجام شده است.
